Privacy Policy

Inbox Automation · Last updated: November 18, 2026

Overview

Inbox Automation is a private tool used by one person, its developer, to manage their own Gmail inbox. It is not a public service and has no other users. This policy explains what Google user data the tool accesses and what happens to it.

Data the tool accesses

With the account owner's consent, the tool uses these Gmail permissions:

  • gmail.readonly: to read and search the owner's messages, threads and labels.
  • gmail.compose: to create and edit draft replies for the owner to review.
  • gmail.modify: to organize the owner's messages, for example by applying or removing labels, archiving, and marking messages as read or unread.

The tool does not access any other Google account, and it does not collect data about anyone other than the account owner and the people who wrote to them.

How the data is used

Mailbox content is used only to carry out the owner's own requests, such as summarizing messages, organizing them (for example, applying labels or archiving), and preparing draft replies. It is not used for advertising, profiling, or any purpose unrelated to managing the owner's own inbox.

AI processing

To summarize messages and write drafts, the tool passes relevant email content to an AI assistant, Claude, provided by Anthropic. That content is processed to perform the task requested and is handled under Anthropic's privacy policy. The developer does not use Google user data to train AI models.

Storage and retention

The tool runs on the owner's own computer. The Google sign-in token is stored locally on that computer. The tool does not copy mailbox contents to any server operated by the developer.

Sharing and disclosure

Google user data is not sold, rented, or shared with third parties, except for the processing by the AI assistant described above, which is needed to perform the owner's requests, and where required by law.

Google API Services User Data Policy

Inbox Automation's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The account owner can withdraw the tool's access at any time at myaccount.google.com/permissions. Deleting the locally stored sign-in token also stops all access.

Changes to this policy

If the tool's behavior changes, this page will be updated and the date above will change.
